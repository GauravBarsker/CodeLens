CodeLens 🔍

Understand How a Compiler Works Internally

CodeLens is an educational compiler analysis and visualization tool designed to help students understand the internal phases of compilation.

Unlike traditional compiler execution tools, CodeLens focuses on explaining what happens inside a compiler when source code is processed.

🎯 Project Objective

To develop an interactive desktop application that analyses a supported subset of C programming language and visually demonstrates compiler operations.

🛠️ Technologies Used

- Python
- PySide6
- C Programming Language (Input)
- Compiler Design Concepts

✨ Core Features

- Lexical Analysis
- Syntax Analysis
- Token Classification
- Error Detection and Reporting
- Parse Tree Visualization
- Symbol Table Representation
- Compilation Stage Visualization

🎓 Project Domain

Compiler Design | Programming Language Processing | Computer Science Education
